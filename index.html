Tải file Excel TKB tại EsHUST
Xem TKB đã ⬇ Xuất PDF hoặc 💾 Lưu trong Browser

Nếu có thắc mắc:

  • 👤 Đông Xuân Đức
  • 👩 Nguyễn Hương Giang

Hướng dẫn sử dụng

  1. Tải file Excel TKB từ EsHUST (Thời khóa biểu dự kiến).
  2. Upload file vào ô kéo thả ở trên.
  3. Nhập tên hoặc mã học phần cần tìm, chọn chương trình học.
  4. Nhấn Tìm lớp để xem danh sách lớp.
  5. Click vào học phần để xem chi tiết các lớp.
  6. Dùng Lưu trong Browser để lưu lại cho lần sau.
